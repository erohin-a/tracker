# Экспорт отчётов
Статус: черновик
Дата: 2026-10-02
Связанные файлы KB: 02_METRICS\02_REPORTS.md, 02_METRICS\01_METRICS.md

## Назначение
Описать все форматы экспорта отчётов (CSV, XLSX, PDF), структуру колонок, особенности форматирования и известные ограничения. Это карта для администратора, который выгружает данные, и для разработчика, который дорабатывает экспорт.

## Содержание

### Общее
- Экспорт доступен из формы `/admin/reports` и из страницы результата `report_result.html`.
- Формат выбирается в поле `fmt`: `html` (просмотр), `xlsx`, `csv`, `pdf`.
- POST-запрос: `POST /admin/reports/generate` с фильтрами и `fmt`.
- Ответ: `StreamingResponse` с нужным `Content-Type` и `Content-Disposition`.
- Один и тот же набор фильтров даёт одинаковые данные во всех форматах.

### Единая структура колонок (CSV и XLSX)
Оба формата используют 15 колонок в одинаковом порядке.

| # | Колонка | Тип (CSV) | Тип (XLSX) | Примечание |
|---|---|---|---|---|
| 1 | Рабочий день | string `DD.MM.YYYY` | date | только для группировок days/months/sessions |
| 2 | Год | int | int | |
| 3 | Месяц_номер | int | int | 1–12 |
| 4 | Месяц | string | string | «Январь»…«Декабрь» |
| 5 | Число | int | int | день месяца |
| 6 | День_недели | string | string | «Пн»…«Вс» |
| 7 | Сотрудник | string | string | |
| 8 | 1C ID | string | string | |
| 9 | Отдел | string | string | для группировки departments — название отдела |
| 10 | Сессий | int | int | |
| 11 | Отработано | string `HH:MM:SS` | timedelta | `[HH]:MM:SS` формат в Excel |
| 12 | С трекером | string `HH:MM:SS` | timedelta | |
| 13 | Интенсивная | string `HH:MM:SS` | timedelta | |
| 14 | Эффективно | string `HH:MM:SS` | timedelta | |
| 15 | Пауза | string `HH:MM:SS` | timedelta | |

**Для группировок, где не применима часть колонок** (например, employees, departments, computers) — поля заполняются пустыми строками. Это сделано для единообразия и pivot-friendly структуры.

### CSV-экспорт
**Особенности:**
- Разделитель `;` (точка с запятой) — удобно для Excel в русской локали.
- Кодировка: UTF-8 с BOM (`\ufeff`) — корректно открывается в Excel без «крокозябр».
- Строка «ИТОГО» в конце файла — содержит суммарные метрики.
- `Content-Type: text/csv; charset=utf-8`.
- Имя файла: `report_{date_from}_{date_to}.csv`.

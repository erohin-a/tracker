# Pivot-таблица (удалено)

**Статус:** черновик
**Дата:** 2026-10-07
**Связанные файлы:** 02_METRICS\04_EXPORTS.md

## Что произошло

Ранее в проекте была встроенная веб-сводная таблица на PivotTable.js (страница
`/admin/reports/pivot`). 06.10.2026 её удалили по решению заказчика:

- интерфейс PivotTable.js оказался неудобным: поля не переименовывались,
  сортировка ломалась, агрегатор сложно настраивать;
- куда проще выгрузить XLSX и построить сводную прямо в Excel.

## Как сейчас строить сводные

1. Открой `/admin/reports`, задай фильтры (период, отделы, сотрудники).
2. Формат: **XLSX**.
3. Открой файл в Excel. Лист «Данные» — плоская таблица, готовая к вставке
   сводной (Вставка → Сводная таблица).
4. Лист «ИТОГО» — отдельная сводка, чтобы не мешала pivot.

Колонки для pivot: `Год`, `Месяц_номер`, `Месяц`, `Число`, `День_недели`,
`Сотрудник`, `1C ID`, `Отдел`, `Сессий`, `Отработано`, `С трекером`,
`Интенсивная`, `Эффективно`, `Пауза`.

## Что удалено из кода

- Роут `GET /admin/reports/pivot` — удалён.
- Эндпоинт `POST /admin/api/pivot-data` — удалён.
- Функция `_build_pivot_data()` — удалена.
- Шаблон `reports_pivot.html` — переименован в `_unused_reports_pivot.html.txt`
  (бэкап, можно удалить).
- PivotTable.js и jQuery — больше не подключаются.

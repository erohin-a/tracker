## Назначение
Описать интернационализацию серверной части «Трекера»: как устроены переводы, как подключаются к шаблонам, как переключать язык. Это карта для разработчика, который добавляет новый язык или новую строку.

## Содержание

### Что такое i18n в проекте
- Простой словарь переводов **без внешних библиотек** (никаких Babel/gettext).
- Все строки интерфейса — в одном файле `server/i18n.py`.
- Два поддерживаемых языка: **RU** (по умолчанию) и **EN**.
- Язык хранится в cookie `tracker_lang`, ставится на 1 год.
- В коде Python — `t("key", lang)`, в шаблонах Jinja — `_("key")`.

### Файл `server/i18n.py`

**Структура:**
```python
DEFAULT_LANG = "ru"

SUPPORTED_LANGS = [
    {"code": "ru", "label": "Русский", "short": "RU"},
    {"code": "en", "label": "English", "short": "EN"},
]

TRANSLATIONS = {
    "menu.employees": {"ru": "Сотрудники", "en": "Employees"},
    "btn.save": {"ru": "Сохранить", "en": "Save"},
    # ... ~200+ ключей
}

def t(key: str, lang: Optional[str] = None) -> str:
    lang = lang or DEFAULT_LANG
    entry = TRANSLATIONS.get(key)
    if entry is None:
        return key  # дырка — видно ключ
    if lang in entry:
        return entry[lang]
    return entry.get(DEFAULT_LANG) or key

def is_valid_lang(code: str) -> bool:
    return code in {l["code"] for l in SUPPORTED_LANGS}
Ключевые моменты:

Ключи вида раздел.элемент: menu.employees, btn.save, dash.title.

Fallback-цепочка: запрошенный язык → DEFAULT_LANG (ru) → сам ключ.

Если ключа нет в словаре — возвращается сам ключ (дырка видна).

Если перевода на запрошенном языке нет — показывается русский.

Подключение к Jinja2
Context processor в web_admin.py:

python
def _i18n_context_processor(request):
    lang = request.cookies.get("tracker_lang") or DEFAULT_LANG
    if not is_valid_lang(lang):
        lang = DEFAULT_LANG

    def _(key):
        return t(key, lang)

    admin_user = request.session.get("admin_user") or {}
    return {
        "current_lang": lang,
        "supported_langs": SUPPORTED_LANGS,
        "_": _,
        "admin": admin_user.get("full_name") or admin_user.get("username") or "",
        "admin_role": admin_user.get("role", ""),
        "current_role": admin_user.get("role", ""),
        "admin_username": admin_user.get("username", ""),
        "admin_id": admin_user.get("id"),
        "admin_department_id": admin_user.get("department_id"),
        "roles_info": ROLES_INFO,
    }

templates.context_processors.append(_i18n_context_processor)
В шаблоне:

jinja
{{ _("menu.employees") }}
{{ _("dash.sessions_today") }}
Функция _ — замыкание на язык запроса, а не глобальная. Это исправляет баг с contextvars в sync-обработчиках FastAPI.

Переключатель языка
Роут:

python
@router.get("/set-lang/{code}")
def set_lang(code: str, request: Request):
    if not is_valid_lang(code):
        code = DEFAULT_LANG
    next_url = request.query_params.get("next") or "/admin"
    if not next_url.startswith("/"):
        next_url = "/admin"
    resp = RedirectResponse(next_url, status_code=303)
    resp.set_cookie(
        "tracker_lang", code,
        max_age=365 * 24 * 3600,
        path="/",
        samesite="lax",
    )
    return resp
В base.html:

jinja
{% for l in supported_langs %}
<a class="btn btn-sm {% if l.code == current_lang %}btn-warning{% else %}btn-outline-light{% endif %}"
   href="/admin/set-lang/{{ l.code }}?next={{ request.url.path }}"
   title="{{ l.label }}">{{ l.short }}</a>
{% endfor %}
Логика:

Cookie tracker_lang — на 1 год.

Редирект на ту же страницу (параметр next).

Защита от open redirect — next должен начинаться с /.

История бага с i18n
Симптом: 500 при переключении на английский.

Причина:

contextvars в sync-обработчиках FastAPI + отложенный рендер Starlette теряли язык.

templates.env.globals["_"] = _ не работал для sync-функций.

Решение: заменить contextvars на bound-функцию в context processor:

python
def _(key):
    return t(key, lang)
lang замкнут, поэтому язык не теряется между вызовами.

Как добавить новую строку
Придумать ключ по схеме раздел.элемент (например, btn.download_pdf).

Добавить в TRANSLATIONS:

python
"btn.download_pdf": {"ru": "Скачать PDF", "en": "Download PDF"},
Использовать:

В шаблоне: {{ _("btn.download_pdf") }}

В коде: t("btn.download_pdf", lang)

Как добавить новый язык (например, de)
Добавить в SUPPORTED_LANGS:

python
{"code": "de", "label": "Deutsch", "short": "DE"},
К каждому ключу добавить поле "de": "...".

Функция t уже устроена так, что fallback сработает:

запрошенный lang → DEFAULT_LANG (ru) → сам ключ.

Проверить переключатель в base.html — он итерирует по supported_langs, ничего менять не нужно.

Проверка полноты переводов
Скрипт для проверки (одноразовый):

python
from server.i18n import TRANSLATIONS, SUPPORTED_LANGS

langs = {l["code"] for l in SUPPORTED_LANGS}
for key, entry in TRANSLATIONS.items():
    missing = langs - set(entry.keys())
    if missing:
        print(f"{key}: missing {missing}")
Дырки в переводах видны сразу: если в шаблоне {{ _("foo.bar") }}, а ключа нет — отобразится foo.bar.

Правила для переводчика
Не переводить: ФИО, отделы, приложения, примечания.

Переводить: все ключи в TRANSLATIONS.

Сохранять формат: {name}, {n}, {time} — плейсхолдеры.

Учитывать длину: EN-строки обычно короче RU, но кнопки могут не влезать.

Единообразие терминов: «Сессия» → «Session», «Отчёт» → «Report», «Смена» → «Shift» — использовать одни и те же термины во всех ключах.

Содержит set_current_lang, get_current_lang, _ — legacy от первых версий.

Сейчас не используется — заменён на bound-функцию в context processor.

Можно удалять, но лучше оставить для совместимости.

Ключевые решения
Свой словарь, а не Babel/gettext. Проще поддерживать, не тянет зависимостей.

Два языка: RU + EN. Достаточно для целевой аудитории.

Bound-функция _ в context processor. Не теряет язык между запросами.

Fallback на DEFAULT_LANG. Если перевод не задан — показывается русский.

Fallback на сам ключ. Дырки видны, не ломают страницу.

Cookie tracker_lang на 1 год. Не нужно выбирать язык при каждом входе.

Иконка ⓘ показывается только если есть перевод для подсказки (*.hint).

web_i18n.py — legacy. Не используется, но не удалён.

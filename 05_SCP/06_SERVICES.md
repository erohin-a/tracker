# Вкладка «Сервисы» (SCP)
Статус: черновик
Дата: 2026-10-12
Связанные файлы KB: 03_SERVER\07_ALEMBIC.md, 03_SERVER\05_TASKS.md, 09_OPS\01_RUNBOOK.md

## Назначение
Вкладка SCP для управления Docker-сервисами Tracker: перезапуск
контейнеров, просмотр логов, работа с миграциями Alembic.
Заменяет ручные команды вида `docker compose restart api`.

Все команды выполняются в отдельном потоке (`QThread`), UI не висит.
Каждая кнопка имеет всплывающую подсказку (tooltip) с описанием:
когда нужно нажимать, сколько занимает, риски.

## Группы кнопок

### Перезапуски
| Кнопка | Команда | Время | Риск |
|---|---|---|---|
| Перезапустить nginx | `docker compose restart nginx` | ~3 сек | нет |
| Перезапустить API | `docker compose restart api` | ~3-5 сек | нет |
| Перезапустить БД | `docker compose restart db` | ~5-10 сек | краткий простой |
| Перезапустить всё | `docker compose restart` | ~15 сек | нет |
| Полная пересборка | `docker compose down && docker compose up -d --build` | 1-3 мин | простой, применяет правки Python |

**Важно:**
- Перезапуск nginx/API — безопасен, применяет правки HTML-шаблонов
  и конфигов, но НЕ правки Python.
- Полная пересборка — применяет правки Python.
- Перезапуск БД и «всё» — под подтверждением (QMessageBox).

### Логи и статус
| Кнопка | Команда |
|---|---|
| Логи API (30) | `docker compose logs api --tail=30` |
| Логи nginx (30) | `docker compose logs nginx --tail=30` |
| Логи БД (30) | `docker compose logs db --tail=30` |
| Статус контейнеров | `docker compose ps` |

### Alembic (только чтение)
| Кнопка | Команда |
|---|---|
| Текущая ревизия | `alembic current` |
| История миграций | `alembic history` |
| Heads | `alembic heads` |

`upgrade`/`downgrade` намеренно НЕ выведены в UI — чтобы случайно не
сломать БД. Их делают только из терминала.

## Реализация

Файл: `control/services_tab.py`.

- `CmdWorker(QThread)` — универсальный фоновый запуск subprocess.
- Автовыбор кодировки: `cp866` для `netsh`/`cmd`/`powershell`/`ipconfig`,
  `utf-8` для `docker`. Иначе вывод netsh превращается в кракозябры.
- Все кнопки блокируются на время выполнения команды.
- Вывод — построчно в `QPlainTextEdit`, копируется.
- Статусная строка: `Готов` / `Работаю: <название>`.

## Известные ограничения
- Список команд захардкожен. Настраиваемые пресеты — в планах.
- Нет прогресса для полной пересборки — только лог по завершении.
- SCP должен запускаться в обычной сессии PowerShell (не от админа).
  PyInstaller под админом выдаёт DEPRECATION (см. `07_QUALITY\02_KNOWN_ISSUES.md`).

### 3.2. Сбор данных

#### 3.2.1. Уникальный идентификатор компьютера

- **Генерация:** UUID v4 при первом запуске.
- **Сохранение:** В `config.json` в директории пользователя.
- **Дополнительные идентификаторы:** MAC-адрес (получение через `uuid.getnode()`) + хеш имени машины (`platform.node()`).
- **Проблема:** При клонировании системы UUID может скопироваться. **Решение:** При первом запуске проверять наличие `computer_id` в файле; если файл отсутствует — генерировать новый UUID. При синхронизации сервер может обнаружить дубликат и уведомить оператора.

#### 3.2.2. Время включения и отключения компьютера

- **Время включения:** Получение через `psutil.boot_time()`. **Важно:** `psutil.boot_time()` на Windows может давать некорректный результат при пробуждении из спящего режима. **Решение:** Использовать `psutil.boot_time()` в сочетании с `wmi` (Windows) или `/proc/uptime` (Linux) для перекрёстной проверки.
- **Время отключения:** Фиксация через обработчик сигналов завершения (`signal.SIGTERM`, `signal.SIGINT`). **Проблема:** При аварийном завершении (BSOD, отключение питания) время не будет зафиксировано. **Решение:** При следующем запуске клиента сравнивать последнее известное время работы с текущим; если разрыв превышает порог — создавать запись о завершении сессии с пометкой «Аварийное завершение».

#### 3.2.3. Название активной программы

**Проблема:** `pygetwindow.getActiveWindow().title` возвращает заголовок окна, а не имя процесса. Заголовок может меняться (например, «Документ1 — Word» ? «Документ2 — Word»), что приведёт к созданию множества ложных записей.

**Решение:** Использовать комбинацию:

```python
import win32gui
import win32process
import psutil

hwnd = win32gui.GetForegroundWindow()
_, pid = win32process.GetWindowThreadProcessId(hwnd)
process = psutil.Process(pid)
process_name = process.name()  # Например, "chrome.exe"
window_title = win32gui.GetWindowText(hwnd)  # Например, "Документ1 — Word"
```

Для Linux (X11):

```python
from Xlib import display, X
import psutil

d = display.Display()
window = d.get_input_focus().focus
wm_name = window.get_wm_name()
pid = window.get_full_property(d.intern_atom('_NET_WM_PID'), X.AnyPropertyType)
process = psutil.Process(pid.value[0])
```

**Рекомендация:** Хранить как `process_name` (стабильный идентификатор), так и `window_title` (для контекста). Группировать программы по `process_name`.

#### 3.2.4. Время работы в активной программе

- **Период опроса:** 5 секунд (настраивается в `config.json`).
- **Логика:**
  - Если `process_name` не изменился — таймер текущей программы увеличивается.
  - Если `process_name` изменился — создаётся новая запись.
  - Если пользователь бездействует (нет ввода) более 60 секунд — таймер программы приостанавливается (но не сбрасывается).
- **Проблема:** Частое переключение окон (Alt+Tab) может создать множество коротких записей. **Решение:** Агрегировать записи с одинаковым `process_name` в пределах одной сессии.

#### 3.2.5. Время работы на клавиатуре и мыши

- **Механизм:** `pynput.keyboard.Listener` и `pynput.mouse.Listener`.
- **Подсчёт времени:**
  - Каждое событие (нажатие клавиши, движение/клик мыши) фиксируется с таймстемпом.
  - «Время работы на клавиатуре» — суммарная длительность интервалов, в которых были нажатия. Если разрыв между нажатиями превышает 60 секунд — интервал не учитывается.
  - Аналогично для мыши.
- **Содержимое нажатий НЕ записывается.**
- **Проблема с Wayland (Linux):** Wayland намеренно блокирует прямой доступ к клавиатуре. `pynput` не будет работать под Wayland без специальных разрешений. **Решение:**
  - Предупредить пользователя при запуске на Wayland.
  - Рекомендовать использовать X11 (Xorg).
  - Альтернатива: использовать `evdev` для доступа к `/dev/input/event*` (требует прав root или добавления пользователя в группу `input`).
- **Проблема с правами (Linux):** Для доступа к `uinput` может потребоваться запуск от root. **Решение:** Создать udev-правило, разрешающее доступ группе пользователей.
- **Проблема с macOS:** macOS ограничивает мониторинг клавиатуры. Требуется явное разрешение в «Настройках безопасности и конфиденциальности» ? «Универсальный доступ». (macOS не является целевой ОС, но упоминается для полноты.)

#### 3.2.6. Обработка бездействия

- **Порог бездействия:** 60 секунд (настраивается).
- **Механизм:** Отслеживать время последнего события клавиатуры/мыши. Если `now - last_event > inactivity_timeout`, считать пользователя неактивным.
- **Важно:** Время бездействия не вычитается из общего времени сессии, но не учитывается в времени активности клавиатуры/мыши.
- **Реализация:** Использовать `idle_time` (кроссплатформенная библиотека) или собственный счётчик на основе событий `pynput`.

# BCE — разработка проекта «Трекер» в чатах

**Все файлы в этой папке — один и тот же проект «Трекер».**  
Он разрабатывался последовательно в нескольких чатах с ИИ. Каждая «часть» — продолжение предыдущей:

- **Часть 1** — постановка задачи, архитектура, первые модели.
- **Часть 2** — сервер, API, аутентификация, партиционирование.
- **Часть 3** — веб-админка, отчёты, шаблоны.
- **Часть 4** — клиент PyQt6, сбор активности, синхронизация.
- **Часть 5** — i18n, темы, напоминания, окно настроек.
- **Часть 6** — SCP, сертификаты, сборка.
- **Часть 7** — установщик, развёртывание, обновления.
- **Часть 8** — финальная сборка, полировка.

## Как читать

1. Начни с [Части 1](part_01.md).
2. Иди по порядку — части 2…8 опираются на предыдущие.
3. Общая картина проекта — в [HANDOFF](../HANDOFF.md) и [00_INDEX](../00_INDEX.md).

## Для ИИ

Это **единый контекст одного проекта**, а не отдельные документы.  
Ключевые сущности (FastAPI, PostgreSQL, PyQt6, HMAC-SHA256, партиционирование `records`, 5 метрик отчётов) упоминаются во всех частях.  
При анализе учитывай сквозную нумерацию и преемственность решений.

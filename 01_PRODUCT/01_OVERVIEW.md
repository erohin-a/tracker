## Назначение
«Трекер» — система автоматизированного учёта рабочего времени сотрудников. Состоит из клиента на ПК сотрудника, серверной части и веб-интерфейса администратора. Собирает данные об активности, хранит их в PostgreSQL и предоставляет отчёты.

## Содержание

### Что делает система
- **Клиент** устанавливается на ПК, работает в фоне и собирает:
  - счётчики нажатий клавиатуры (без содержимого);
  - клики и скролл мыши;
  - имя активного приложения и заголовок окна;
  - периоды простоя (idle).
- **Клиент** отправляет данные на сервер по HTTPS с HMAC-подписью каждой записи.
- **Сервер** проверяет подписи, хранит данные, ведёт аудит.
- **Администратор** работает через веб-интерфейс: сотрудники, отделы, ПК, отчёты, настройки.

### Границы системы
**Внутри системы:**
- сбор активности на ПК;
- офлайн-буфер в SQLite, синхронизация при появлении связи;
- регистрация ПК по bootstrap-токену;
- веб-админка: CRUD сотрудников/отделов/ПК, отчёты, настройки, календарь, роли, аудит;
- планировщик: партиции, агрегаты, автозакрытие зависших сессий;
- SCP (Server Control Panel) — управление сертификатами, сборкой клиента, admin-доступом.

**Вне системы:**
- интеграция с 1С (поле `external_id` есть, механизма обмена нет);
- автообновление клиента (эндпоинт версий есть, публикация через UI не сделана);
- мобильное приложение;
- GPS-трекинг;
- скриншоты экрана;
- запись содержимого нажатий.

### Целевые пользователи
| Роль | Что делает |
|---|---|
| Администратор | Управляет системой через веб-админку и SCP |
| Руководитель отдела | Смотрит отчёты по своему отделу |
| Кадровик | Ведёт сотрудников, отделы, графики |
| Наблюдатель | Только просмотр отчётов |
| Сотрудник | Устанавливает клиент, нажимает «Начать работу» / «Конец работы» |

### Объём внедрения
- до 50 сотрудников на один сервер (при большем — партиционирование и оптимизация);
- клиент под Windows 10/11 (Linux/macOS — не собраны);
- сервер — Linux Ubuntu 22.04 или Windows с Docker Desktop.

## Ключевые решения
- Клиент не пишет содержимое нажатий — только счётчики.
- Регистрация нового ПК только по одноразовому bootstrap-токену.
- Все записи подписаны HMAC-SHA256.
- Офлайн-first: локальная SQLite с WAL, синхронизация с backoff.
- Партиционирование `records` по месяцам.
- Настройки (часовой пояс, начало дня, порог паузы) — глобальные, редактируются в админке.
- Персональные настройки напоминаний — в `employee_settings` (nullable поля = «как у всех»).

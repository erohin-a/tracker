# Глоссарий
Статус: черновик
Дата: 2026-10-02
Связанные файлы KB: 02_METRICS\01_METRICS.md, 03_SERVER\03_MODELS.md, 04_CLIENT\02_COLLECTOR.md

## Назначение
Единый словарь терминов проекта «Трекер». Используется во всех KB-файлах, чтобы избежать разночтений. Все определения согласованы с заказчиком и реализацией.

## Содержание

### Объекты
| Термин | Определение |
|---|---|
| **Компьютер** | Зарегистрированный ПК сотрудника. Хранится в `computers`. Идентификатор — `computer_uid` (UUID v4). |
| **Сотрудник** | Человек, чьё время учитывается. Хранится в `employees`. Идентификатор — `id` (целое), внешний — `external_id` (1C ID). |
| **Отдел** | Группа сотрудников. Хранится в `departments`. У сотрудника — `department_id`. |
| **Сессия** | Период от нажатия «Начать работу» до «Конец работы» (или до авто-закрытия). Хранится в `work_sessions`. Идентификатор — `session_uid`. |
| **Запись** | Единичное событие внутри сессии: активность, окно, idle. Хранится в `records`. Идентификатор — `record_uid`. |
| **Запись активности** | `records.kind = 'activity'`. Отправляется раз в 5 сек, если за это время были нажатия/клики/скролл. |
| **Запись окна** | `records.kind = 'window'`. Отправляется при смене активного окна (edge-triggered). |
| **Запись idle** | `records.kind = 'idle'` и `'idle_end'`. Отправляется при переходе через порог бездействия (60 сек). |

### Метрики (кратко; формулы — в `02_METRICS\01_METRICS.md`)
| Термин | Смысл |
|---|---|
| **Отработано (span)** | От старта 1-й до конца последней сессии за день (табель). |
| **С трекером (union)** | Объединение интервалов активности всех сессий без двойного счёта (2 ПК одного сотрудника). |
| **Интенсивная** | 5 сек × количество activity-событий с реальной активностью. |
| **Эффективно** | Сумма интервалов активных окон (обрезается по gap и idle). |
| **Пауза** | `Σ pause_seconds` + (Отработано − С трекером). Всё неэффективное время. |
| **Аварийная сессия** | Сессия с `abnormal_termination = True` — закрыта не пользователем, а системой/падением. |
| **Не привязан** | Сессия с `employee_id = NULL`. Не попадёт в отчёты по сотрудникам. |

### Технические термины
| Термин | Определение |
|---|---|
| **HMAC-подпись** | HMAC-SHA256 от канонической JSON-строки с секретом `client_secret`. Защита от подмены данных. |
| **Bootstrap-токен** | Одноразовый токен для регистрации нового ПК. Хранится как хеш в `bootstrap_tokens`. |
| **client_secret** | Секрет ПК, выдаётся при регистрации. Хранится зашифрованным (`Fernet`) в `computers.client_secret_enc`. |
| **SECRET_ENCRYPTION_KEY** | Fernet-ключ из `.env`, используется для шифрования `client_secret` в БД. |
| **JWT_SECRET** | Секрет для сессионных cookie админки. |
| **ADMIN_API_KEY** | Пароль для входа в админку под логином `admin`, а также токен для admin API. |
| **Idempotency (идемпотентность)** | Повторная отправка записи с тем же `record_uid` не создаёт дубликат. |
| **Партиционирование** | Разбиение `records` на подтаблицы `records_YYYY_MM`. Ускоряет запросы и удаление старых данных. |
| **include_object** | Хук Alembic, исключающий партиции `records_*` из автогенерации миграций. |
| **WAL** | Write-Ahead Logging в SQLite. Позволяет читать и писать параллельно. |
| **Soft delete** | Пометка «удалён» (`deleted_at`), запись остаётся в БД. Есть у `computers`, `records`, `work_sessions`. |
| **Advisory lock** | Механизм PostgreSQL, гарантирующий, что планировщик запущен только в одном воркере. |
| **SCP** | Server Control Panel — десктопное приложение администратора сервера. |
| **KB** | Knowledge Base — база знаний в `D:\tracker\docs\`. |
| **client-config** | Эндпоинт `/api/v1/client-config`, отдаёт клиенту эффективные настройки. |
| **heartbeat** | Запрос клиента раз в 3 минуты, обновляет `last_seen_at` на сервере. |
| **stale session** | «Висящая» сессия без `session_end` дольше `stale_session_hours`. |

### Роли и сущности
| Термин | Определение |
|---|---|
| **admin** | Полный доступ. |
| **operator** | Ежедневная работа, без администрирования. |
| **hr** | Справочники + отчёты. |
| **manager** | Отчёты по своему отделу. |
| **viewer** | Только просмотр. |
| **ROLES_INFO** | Словарь с описанием ролей на RU/EN в `security_passwords.py`. |
| **AuditLog** | Журнал всех значимых действий администратора. |

### Периоды и время
| Термин | Определение |
|---|---|
| **Рабочий день (workday_date)** | Дата, к которой относится сессия. Определяется по `workday_start_hour`: сессия, начавшаяся до этого часа, относится к предыдущему дню. |
| **workday_start_hour** | Настраиваемый час (0–23), по умолчанию 6. |
| **report_timezone** | Часовой пояс для отображения в отчётах, по умолчанию `Europe/Moscow`. |
| **activity_gap_minutes** | Порог разрыва между событиями (по умолчанию 5 мин). Всё, что больше — не считается работой. |
| **stale_session_hours** | Порог автозакрытия «висящих» сессий (по умолчанию 2 ч). |
| **idle_close_minutes** | Порог бездействия на клиенте для авто-закрытия сессии (по умолчанию 30 мин). |

## Ключевые решения
- Один термин — одно определение. Дублирование запрещено.
- Все термины, встречающиеся в других KB-файлах, должны быть здесь.
- Русские термины — основа, английские — только там, где нет устоявшегося перевода (HMAC, WAL).
- Метрики описаны кратко; формулы — в отдельном файле `02_METRICS\01_METRICS.md`.

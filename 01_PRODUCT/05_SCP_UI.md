## Назначение
Описать SCP (Server Control Panel) — настольное приложение для администратора сервера Tracker. SCP нужен для операций, которые неудобно или опасно делать через веб-админку: работа с TLS-сертификатами, сборка клиента, сброс ключей.

## Содержание

### Что такое SCP
- Отдельное десктопное приложение на Python (папка `control/`).
- Запуск: `python -m control.main` из папки `D:\tracker`.
- Работает на том же ПК, где развёрнут сервер (или имеет доступ к файлам проекта).
- Взаимодействует с сервером напрямую: файлы, Docker, SQL — не через API.

### Окно SCP
- Одно окно с вкладками (`QTabWidget`).
- Общий стиль похож на админку (тёмный navbar, светлый контент).
- Каждая вкладка = отдельная операция.

### Вкладки (текущие и запланированные)

| # | Вкладка | Назначение | Статус |
|---|---|---|---|
| 1 | Информация | Состояние контейнеров, версии, uptime | в работе |
| 2 | Сертификаты (CertificateTab) | Просмотр, обновление, экспорт ca.pem | частично |
| 3 | Сборка клиента (BuildTab) | PyInstaller + Inno Setup | не создан |
| 4 | Администрирование (AdminTab) | Сброс пароля веб-админа, ADMIN_API_KEY | не создан |
| 5 | Бэкапы | pg_dump, ротация, восстановление | в планах |
| 6 | Планировщик | Просмотр scheduled_tasks и task_runs | в планах |
| 7 | Логи | Просмотр `docker compose logs` | в планах |

### Вкладка «Сертификаты» (CertificateTab)
**Показывает:**
- CN (Common Name) текущего сертификата.
- SAN (Subject Alternative Names).
- SHA-256 отпечаток.
- Даты выпуска и истечения.
- «Осталось дней: N (OK / WARNING / EXPIRED)».

**Действия:**
- «Обновить сертификат» — открывает диалог:
  - CN (редактируемое).
  - SAN (редактируемое, через запятую).
  - Срок действия в днях (спинбокс).
  - Чекбокс «Копировать в `client/ca.pem`».
  - Чекбокс «Перезапустить nginx».
  - Кнопка «Сгенерировать».
- «Сохранить ca.pem в файл» — для раздачи сотрудникам (в планах).
- «Показать отпечаток» — копирование в буфер.

**Что делает генерация:**
1. Бэкап текущего сертификата 
 `certs/backup_YYYYMMDD_HHMMSS/`.
→
2. Генерация нового (RSA 4096).
3. Запись в `certs/fullchain.pem` и `certs/privkey.pem`.
4. Опционально — копия `fullchain.pem` 
 `client/ca.pem`.
→
5. Опционально — `docker compose restart nginx`.
6. Показ нового отпечатка и срока.

**⚠ Последствия смены сертификата:** все текущие клиенты отключатся (`CERTIFICATE_VERIFY_FAILED`). Нужно раздать новый `ca.pem` и пересобрать установщик.

Показывает:

### Что НЕ делает SCP
- Не управляет сотрудниками/отделами (это в веб-админке).
- Не редактирует настройки приложения (только `.env` через AdminTab).
- Не делает отчёты.
- Не работает удалённо (только локально на сервере).

## Ключевые решения
- SCP — только для операций «уровня сервера», не для контента.
- Операции с сертификатами — через OpenSSL CLI (`subprocess`).
- Бэкап сертификата — до генерации, обязательно.
- После смены сертификата — авто-напоминание о пересборке установщика.
- Показ отпечатка — SHA-256 в hex, первые 16 и последние 16 символов в UI.
